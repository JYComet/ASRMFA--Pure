# Qwen3 主管线与固定时间戳正则化

## 目标与范围

主管线改为 Qwen3 文本／时间戳来源；保留 MFA 全套逻辑、锚点能量修正、英文 MFA、后处理与质量过滤。用户进一步明确：不冻结最终边界，不删除 MFA 的任何正常修正逻辑。禁止的是识别／预对齐失败时切回 FunASR/NVASR。

选择扩展现有 `qwen3_prealign.py` 六文件交接，而不另建 MFA 管线。保留 `ctc_prealign` 配置名和 `ctc_pretg` 路径，便于复用调度、词典、封存、恢复和审计代码。这里的 CTC 是历史接口名，不表示 Qwen 产生 CTC 帧或音素时间戳。

## 数据流

```text
无参考文本：Qwen3 ASR → Qwen3 ForcedAligner ┐
有参考文本：参考文本 → Qwen3 ForcedAligner ├→ 固定正则化
                                         ┘
→ 既有文本／英文规范化 → 锚点能量修正 → MFA → 英文 MFA → 后处理／审计
```

`reference_mode: authority` 必须有参考文本，仅需要 ForcedAligner 权重；`fallback` 始终识别；`auto` 按文件决定。缺少时间戳、词序不匹配、非法区间或推理失败都记录失败，不请求其他 ASR 模型。

## 两份时间轴的职责

Qwen 与原 FunASR 时间戳承担相同职责，不因更换模型而冻结最终边界：

- **基础参考时间轴**：`ctc_pretg` 保存固定正则化后的文本、词和停顿边界，通过原始 manifest 封存。供 MFA 和后处理参考、比对及追溯，处理过程不回写这份数据。模型未经正则化的原始坐标另存于 `raw_start_s/raw_end_s` 等来源字段。
- **可修改的工作时间轴**：`ctc_pretg_adj` 是独立物理副本，能量修正在这里修改词和标点区间；MFA 及后处理继续生成各自的工作结果。后续可按已有算法延长、缩短、移动、合并和重新分配边界，不要求与基础参考坐标相等。
- **最终输出**：以全部处理完成时的 `words` 时间轴为准，汉字和音素等派生层与它同步。基础坐标、原始模型坐标以及早先阶段的仲裁结果均不能在发布时把它恢复回去。

来源校验保护基础参考、词序和文本身份；它不把基础坐标当成最终结果的几何限制。
各算法的搜索范围和相邻词保护属于该次修正的判断条件，不意味着工作时间轴不可继续修改。
最终的 geometry freeze 只封存已经处理完的输出并检查派生层一致性，不冻结输入锚点。

例如 LAria_00004 的“家”：基础参考结束于 3.760 秒，能量修正后的工作锚点结束于
4.085 秒，MFA 与后处理得到最终 4.050 秒；最终文件保存 4.050 秒，前两份证据各自保留。

## 固定正则化契约

实现位于 `scripts/qwen3_timestamp_normalization.py`，版本为 `qwen3-timestamp-normalization-v2`。不是可关闭的配置阶段。每个 Qwen 结果在写任何交接文件前执行一次；函数可重复调用而不累积修复。

Qwen 提供词／字区间，停顿根据相邻区间及首尾间隙分类。采用 TextGrid 的整数微秒精度和仓库现有阈值：

| 停顿 | 区间时长 | 正则化 |
|---|---|---|
| sp0 | `< 0.2s` | 延长前词结束时间，吸收整个停顿 |
| sp1 | `0.2s ≤ d < 0.5s` | 保留对应原标点；无标点才补 `…`，保存停顿区间（开头除外） |
| sp2 | `0.5s ≤ d < 1.5s` | 同上 |
| sp3 | `d ≥ 1.5s` | 同上 |

开头任何等级的 sp 都保留为边界静音，不产生省略号；末尾 sp0 并入末词。非开头长停顿优先使用该词边界原有标点（包括连续标点），只有无标点时才补省略号。显式 sp 标签不覆盖原标点，开头标签不转省略号。标点不进入 MFA 词典或 `.lab`，使用既有标点侧车携带其时间区间。

例如 `你[0.1,0.3] 好[0.4,0.6] 啊[1.1,1.3]`，音频长 1.4 秒，原文 `你好，啊！`：修复后为 `你[0.1,0.4] 好[0.4,0.6] ，[0.6,1.1] 啊[1.1,1.4]`，文本 `你好，啊！`。

在后续 `adjust_ctc_boundaries.py` 能量修正中，Qwen 词与停顿必须通过正则化版本和相邻词序号对应。
这种停顿的起点是模型估计边界，允许前词延音继续进入停顿区间：沿用连续 30 毫秒低能量的判定，
最多向后搜索 0.6 秒且不越过停顿结束；词尾与标点起点同步移动，至少保留 60 毫秒标点区间。
其他来源或未绑定的标点仍保留既有边界约束。原始 Qwen 时间戳不改写，MFA 使用修正后的工作副本。
能量阶段的缓存还必须包含逐词执行标记；纯中文无需英文 geometry 字段，不代表已经执行能量修正。

## 数据与文本身份

- `.TextGrid`、`.lab`、`_tokens.jsonl` 共用修复后的词序与锚点。
- `_punct.json` 保存原标点或新增省略号、原始间隙、sp 等级、左右词序号和 Qwen 来源。`source: ctc` 是旧侧车的传输格式，另用 `provider` 和 `lexical_timing_source` 明确实际来源。
- `_text_cn.txt`、参考模式的 `_ref.txt` 为修复后文本；`_text_raw.txt` 和 manifest 的 `text_original` 保留原文。
- token 保留模型 `raw_start_s/raw_end_s`、既有量化修复记录和本次正则化之前的区间；英文 canonical span/hash 与修复后锚点保持一致。
- 原始参考文本摘要和修复后参考文本摘要分开保留。所有词携带相同的修复文本 SHA256。
- 后处理和独立审计校验修复文本与 token 摘要，并使用该文本作为有效来源，防止重新读取原始参考文件覆盖省略号。原始参考文件不修改。
- 正则化版本及实现文件摘要纳入 producer identity 与主管线缓存指纹。旧产物不能跳过新步骤；模型或身份变化要求新工作区。

## 运行参数迁移

`full` 和历史无参考模式名 `nvrasr_fallback` 默认及配置迁移后的 provider 均为 `qwen3_hf`；CLI 覆盖 mode 后再次应用迁移。显式旧 `nvasr/funasr` provider、已知 NVASR 模型路径及原 ASR 解释器路径迁移时打印说明。其他自定义模型／解释器路径由用户配置，模型预检会校验。

保留选择清单、offset、limit、timeout、device、上下文、语言、生成长度、收据、失败项重试等接口。`all_gpus` 使用进程可见的 CUDA 设备，每卡一个模型实例；`batch_size` 控制每卡排队的任务数量，模型 API 仍按单条音频推理。发布结果保持输入顺序且仅由主 producer 写入。受 `CUDA_VISIBLE_DEVICES` 约束，不启动 NVASR 进程。

NVASR 特有的 NVV 声学分类、`nvv_bias` 和 decoder `pause_threshold` 无 Qwen 等价能力：旧开关在迁移时明确提示关闭／移除，不能声称 Qwen 已实现事件检测。参考 NVV 标签仍明确拒绝。单条 ForcedAligner 音频长度上限仍为 300 秒。独立历史 NVASR/anchored_nvv 脚本与既有封存产物不删除。

## 验收

覆盖准确停顿阈值、首尾停顿、英文表面文本和 canonical 元数据、幂等性、无效区间、文本篡改、两种参考模式、纯参考无需 ASR 权重、多 GPU 任务所有权及资源释放、默认配置迁移、封存／工作副本／恢复、实际后处理输出和独立审计读取。使用合成 MFA TextGrid 验证交接，保留所有既有 MFA 回归测试。真实 GPU 模型推理和真实 MFA 声学对齐需单独短音频验收，不以模拟后端测试替代。
